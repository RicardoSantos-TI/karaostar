# KaraôStar 🎤

Karaokê com pontuação para festas: solo, duelo, dueto e modo festa.

- **No navegador:** https://karaostar-app.web.app (cantar as músicas de demonstração e salvar os pontos na nuvem com a conta Google)
- **Completo para Windows** (buscar e baixar músicas do YouTube, IAs): baixe em [Releases](../../releases/latest)

## Como usar a versão para Windows

1. Baixe **KaraoStar-portatil.zip** em [Releases](../../releases/latest)
2. Descompacte (botão direito → *Extrair tudo*)
3. Abra a pasta e dê dois cliques em **iniciar.bat**

Não precisa instalar nada: o Python vem junto na pasta. Funciona também a partir de um pendrive ou SSD externo.
